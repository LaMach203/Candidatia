COMMENT METTRE "CANDIDATIA" EN LIGNE - GUIDE PAS A PAS POUR JAROD
====================================================================
Le site est déjà codé et prêt (page d'accueil + 3 articles) dans ce dossier.
Il ne reste que des étapes qui touchent à la création de comptes / achats,
que tu dois faire toi-même. Alice t'accompagne à l'oral pour chaque étape.

ETAPE 1 - Créer un compte GitHub (gratuit)
--------------------------------------------
1. Va sur github.com
2. Crée un compte gratuit (email + mot de passe)
=> Sers-toi de ce compte, ne le partage à personne. Une fois créé, dis-le
à Alice pour la suite.

ETAPE 2 - Créer un "repository" (juste un espace de stockage du site)
------------------------------------------------------------------------
1. Une fois connecté, clique sur "New repository"
2. Nomme-le par exemple "candidatia"
3. Laisse-le en "Public"
4. Ne coche rien d'autre, clique "Create repository"

ETAPE 3 - Envoyer les fichiers du site sur GitHub
----------------------------------------------------
Une fois le compte et le repository créés, dis-le à Alice : elle peut
t'accompagner pour envoyer (via "git push" ou en glissant les fichiers
directement sur le site GitHub) tout le contenu de ce dossier vers le
repository.

ETAPE 4 - Activer l'hébergement gratuit (GitHub Pages)
----------------------------------------------------------
1. Dans le repository, va dans "Settings" puis "Pages"
2. Choisis la branche "main" comme source
3. GitHub te donne une adresse du type "tonpseudo.github.io/candidatia"
=> Le site est en ligne, gratuitement, à cette adresse.

ETAPE 5 (plus tard) - Acheter un nom de domaine
---------------------------------------------------
Quand tu veux passer d'une adresse "github.io" à un vrai nom de domaine
(ex: candidatia.fr) :
1. Achète le nom de domaine chez un registrar (ex: OVH, Gandi, Namecheap) -
   quelques euros par an, c'est la seule vraie dépense du projet.
2. Dans les réglages du domaine, ajoute les enregistrements DNS fournis par
   GitHub Pages (Alice te guide pour les valeurs exactes le moment venu).
3. Dans "Settings > Pages" du repository, indique ton nom de domaine.

ETAPE 6 (plus tard) - S'inscrire aux programmes d'affiliation
------------------------------------------------------------------
Pour chaque outil IA mentionné dans les articles (ChatGPT/Claude n'ont pas
forcément de programme d'affiliation grand public, mais Rezi, Kickresume,
Teal, Yoodli, Final Round AI en ont souvent) :
1. Cherche "affiliate program" sur le site de l'outil, ou dans son footer.
2. Inscris-toi avec ton propre compte/email.
3. Une fois accepté, tu obtiens un lien unique - donne-le à Alice pour
   qu'elle remplace les notes "[Lien d'affiliation à ajouter]" dans les
   articles par ce lien.
